# Web管理画面

無人販売支援システムのWeb管理画面です。

本Web管理画面では、商品登録、在庫管理、売上履歴、通知履歴、メール通知先設定、session.json生成・通知送信を行います。

また、複数の無人販売所で利用できるように、初回登録・ログイン機能を追加し、販売所ごとにデータを分離して管理します。

## 配置

```text
app/web_admin/
├─ web_app.py
├─ data_store.py
├─ line_notify.py
├─ templates/
│  ├─ index.html
│  ├─ login.html
│  └─ register.html
├─ static/
│  ├─ style.css
│  └─ products/
└─ README.md
```

古い `Flask/` フォルダは使用しません。

## 起動方法

リポジトリ直下で実行します。

```bash
pip install -r requirements.txt
python -m app.web_admin.web_app
```

起動後、ブラウザで以下にアクセスします。

```text
http://127.0.0.1:5000
```

同じネットワーク内の別端末からアクセスする場合は、実行しているPCまたはRaspberry PiのIPアドレスを指定します。

```text
http://192.168.x.x:5000
```

## 初回登録・ログイン機能

複数の農家や無人販売所で利用できるように、初回登録機能とログイン機能を追加しています。

初回登録では、以下の情報を登録します。

```text
販売所名
管理者名
メールアドレス
パスワード
```

登録後は、メールアドレスとパスワードでログインします。

ログイン後は、ログインしたユーザーに紐づいた販売所の情報だけが表示されます。

これにより、複数の農家や販売所が同じWebシステムを利用する場合でも、他の販売所の商品情報、在庫情報、売上履歴、通知履歴、通知先メールアドレスを閲覧・変更できないようにしています。

## 複数販売所対応

初回登録時に、販売所ごとの `shop_id` を発行します。

商品、在庫、売上履歴、通知履歴、通知先メールアドレスは、販売所ごとに分けて保存します。

```text
山田農園
→ shop_001 のデータだけを表示・更新

佐藤直売所
→ shop_002 のデータだけを表示・更新
```

ログイン中のユーザーに対応する `shop_id` をもとに、表示・更新するデータを切り替えます。

これにより、複数人が同じWebシステムを利用しても、自分の販売所のWebページだけを管理できます。

## ホーム画面

ホーム画面では、ログイン中の販売所に関する概要を表示します。

主な表示内容は以下です。

```text
登録商品数
現在の在庫数
売上履歴件数
通知履歴件数
```

また、ホーム画面から `session.json生成・通知送信` を実行できます。

この機能を実行すると、session.json の生成、履歴反映、メール通知をまとめて行います。

## 在庫管理

在庫画面では、ログイン中の販売所の商品・在庫情報を管理します。

主な機能は以下です。

```text
商品登録
在庫数の変更
価格の設定
単重量の設定
商品画像の表示
```

登録した商品情報や重量センサー設定は、制御側と共通の `app/config.py` に反映されます。

## 通知履歴

通知画面では、ログイン中の販売所で発生した通知履歴を確認できます。

主な通知履歴は以下です。

```text
購入通知
万引き通知
動画添付通知
システム通知
```

他の販売所の通知履歴は表示されません。

## メール通知機能

LINE通知からメール通知に変更しました。

購入時や万引き判定時に、登録済みの通知先メールアドレスへメール通知を送信します。

初回登録で入力したメールアドレスは、ログイン用メールアドレスとして使用するだけでなく、通知先メールアドレスとしても自動登録されます。

そのため、利用者は設定画面で別途メールアドレスを登録しなくても、登録直後から通知を受け取ることができます。

設定画面の通知先登録は、家族や共同管理者など、追加で通知したい相手を登録するために使用します。

通知先ごとに、以下の通知設定を変更できます。

```text
購入通知
万引き通知
動画通知
システム通知
有効 / 無効
```

## 動画添付通知

万引き判定時には、監視動画 `monitor.mp4` をメールに添付して送信します。

動画ファイルが大きい場合は、自動で圧縮してから添付します。

圧縮後の動画は、メール添付の安定性を優先するため音声なしで作成されます。

圧縮後の動画は、以下のフォルダに実行時データとして保存されます。

```text
mail_attachments/
```

このフォルダはGit管理しません。

## session.json生成・通知送信

ホーム画面の `session.json生成・通知送信` を実行すると、session.json の生成、履歴反映、メール通知を自動で行います。

判定結果が `normal` の場合は、購入通知メールを送信します。

```text
normal判定
→ 購入通知メールを送信
→ 売上履歴に反映
→ 通知履歴に反映
```

判定結果が `theft` の場合は、万引き通知メールを送信し、監視動画を添付します。

```text
theft判定
→ 万引き通知メールを送信
→ 監視動画を添付
→ 通知履歴に反映
```

通知は、ログイン中の販売所に登録されている通知先メールアドレスにのみ送信されます。

## 設定画面

設定画面では、通知先メールアドレスを管理します。

初回登録時のメールアドレスは自動で通知先に登録されるため、最初から通知を受け取ることができます。

追加で通知先を増やしたい場合は、設定画面から登録します。

例：

```text
家族にも通知したい
共同管理者にも通知したい
万引き通知だけ別の担当者にも送りたい
```

設定画面では、通知先ごとに通知種別を設定できます。

```text
この通知先を有効にする
購入通知を送る
万引き通知を送る
動画通知を送る
システム通知を送る
```

## 送信用メール設定

メール送信に使用する送信用メールアドレスは、以下のファイルで設定します。

```text
app/web_admin/line_notify.py
```

設定箇所は以下です。

```python
SMTP_USERNAME = ""          # 例: "your_account@gmail.com"
SMTP_PASSWORD = ""          # Gmailのアプリパスワード
SMTP_FROM_ADDRESS = ""      # 空の場合はSMTP_USERNAMEを使用
```

Gmailを使用する場合、`SMTP_PASSWORD` には通常のGoogleアカウントのパスワードではなく、Googleアカウントで発行したアプリパスワードを設定します。

例：

```python
SMTP_USERNAME = "your_account@gmail.com"
SMTP_PASSWORD = "Googleで発行したアプリパスワード"
SMTP_FROM_ADDRESS = ""
```

`SMTP_FROM_ADDRESS` が空の場合は、`SMTP_USERNAME` が送信元として使用されます。

## 今後の課題

現在はJSONファイルでユーザー情報や販売所データを管理しています。

実運用を想定する場合は、SQLiteやMySQLなどのデータベースを利用し、ユーザー情報、販売所情報、履歴情報をより安全に管理する必要があります。

また、送信用メールアドレスやアプリパスワードをコード内に直接記述すると、GitHubに公開した際に漏洩する危険があります。

そのため、実運用では環境変数や `.env` ファイルを用いて管理することが望ましいです。
